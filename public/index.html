How to play

Use the clues and your actions to work out the machine.

01 · Take one action

On your turn, reveal a fresh clue, check a clue privately, shift a dial, or play an Event Card.

Revealing clues

You can reveal clues dealt in the current round. Older clues stay in your private archive, where you can still verify them.

02 · Lock your prediction

Once every player has acted, secretly choose a value from 0–3 for A, B and C. Your guess stays hidden until everyone locks.

03 · Read the result

The room admin sets the rewards for one- and two-dial matches. A perfect guess wins immediately. Otherwise, a hidden automatic event changes the machine before the next round. After the final round, the highest score wins; ties share the win.

Admin

The admin can be a separate non-player, set scoring values, see the current dials, and manage players and spectators. Before the game starts, an admin can also take a seat as a player. Scoring values can be negative: a negative value deducts points and a positive one adds them. If the last admin leaves the role, they can still start the game and continue rounds, but nothing more. The first player changes each round. Late arrivals can watch.

Quantum Jump

Choose one dial and a previous version. That dial returns to its position from that version; the other two dials do not change.

Clues

Every clue records a true dial value from an earlier version. Interference and Event Cards change the machine, so old facts can go stale.
